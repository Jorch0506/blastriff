# Blast Riff

Blast Riff — Heavy Metal Trivia Game. Prove you're a Trve Metalhead.

Built with Next.js 14 (App Router), TypeScript, Tailwind CSS, Supabase, Stripe, Upstash Redis, Zustand, and Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.
